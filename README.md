# 🌦️ WeatherWeek

Учебное погодное приложение на React и Vite: поиск города, прогноз на неделю и график почасовой температуры на Canvas. Серверная часть не требуется.

## Возможности

- Поиск города с подсказками и запрос по координатам.
- Определение местоположения через браузер.
- Минимальная и максимальная температура на семь дней.
- График почасовой температуры.
- Русские и английские подписи основного интерфейса и графика; панель настроек пока на английском.
- Выбор часового пояса и единиц температуры (Celsius/Fahrenheit).
- Обработка ошибок сети, координат и доступа к геолокации.

## Быстрый старт

Понадобятся Node.js 22 и npm. Версия Node закреплена в `.nvmrc`; при установленном nvm выполните `nvm use`. Затем из корня проекта:

```bash
npm ci
npm run dev
```

Откройте адрес, указанный Vite в терминале (обычно `http://localhost:5173`). Не открывайте `index.html` через `file://`: исходники должны обрабатываться Vite. Для сборки и просмотра результата:

```bash
npm run build
npm run preview
```

Сборка попадает в `dist/`; preview обычно доступен на `http://localhost:4173`. Для публикации нужен статический хостинг каталога `dist/`. `npm run preview` предназначен для локальной проверки сборки.

## Данные и ограничения

Браузер напрямую обращается к [API прогноза Open-Meteo](https://open-meteo.com/en/docs) и [API геокодирования](https://open-meteo.com/en/docs/geocoding-api). Для загрузки погоды нужен интернет; ключи API и переменные окружения в этой реализации не используются. Геолокация требует разрешения браузера и защищённого контекста (HTTPS или localhost). При использовании геолокации координаты передаются Open-Meteo для получения прогноза.

Приложение запрашивает данные в Celsius и преобразует значения для показа в Fahrenheit. График берёт первые 24 часа прогноза и использует фиксированную шкалу от -35 до +35 °C. Метка текущего часа ориентируется на часы браузера, поэтому при выборе другого часового пояса может не совпадать с местным временем города.

Координаты проверяются в диапазонах [-90, 90] и [-180, 180], включая нулевую широту и долготу. Пустые, нечисловые и бесконечные значения не принимаются.

Остаются ограничения учебной реализации: ответы поиска города не отменяются при следующем вводе; подписи некоторых сетевых ошибок ещё не локализованы. В шапке сохранено исходное название лабораторной. Пользовательские настройки не сохраняются между перезагрузками страницы.

## Проверка

`npm ci` восстанавливает версии из `package-lock.json`, `npm test` проверяет валидацию координат встроенным `node:test`, `npm run build` проверяет производственную сборку. GitHub Actions выполняет эти команды для push и pull request на Node.js 22. Тесты покрывают числовой и строковый ноль, пустые/нечисловые/бесконечные значения и границы диапазонов. Проверки не обращаются к погодному API; автоматических тестов интерфейса, геолокации и отрисовки Canvas пока нет.
