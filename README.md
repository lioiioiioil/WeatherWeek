# 🌦️ WeatherWeek

Погодное приложение на React: поиск города, прогноз на неделю и интерактивный график температуры.

![Vite](https://img.shields.io/badge/Vite-5-646CFF?logo=vite&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-ES_modules-F7DF1E?logo=javascript&logoColor=black)

## Возможности

- Поиск города с подсказками и запрос по координатам.
- Определение местоположения через браузер.
- Минимальная и максимальная температура на семь дней.
- График почасовой температуры.
- Русский и английский интерфейс, выбор часового пояса и единиц температуры.
- Обработка ошибок сети, координат и доступа к геолокации.

## Быстрый старт

Понадобятся Node.js 22 LTS и npm. Выполните из корня проекта:

```bash
npm ci
npm run dev
```

Откройте адрес, указанный Vite в терминале. Для сборки и просмотра результата:

```bash
npm run build
npm run preview
```

## Данные и ограничения

Код обращается к API прогноза и геокодирования Open-Meteo; переменные окружения и ключ API в этой реализации не используются. Для загрузки погоды нужен интернет. Геолокация требует разрешения браузера и защищённого контекста (HTTPS или localhost).

Это учебная версия: в шапке сохранено исходное название лабораторной. Серверной части и хранения пользовательских данных на собственном сервере нет. `package-lock.json` сохранён вместе с исходниками; зависимости восстанавливаются через `npm ci`.

## Проверка подготовки — 12 октября 2026

`npm ci` и `npm run build` успешно выполнены на macOS (Apple Silicon). Проверена производственная сборка; живые ответы погодного API и геолокация в браузере отдельно не проверялись.
